### 🚀 Featured Projects

#### 🏭 Automate — Bakery Management System
> *Because even bread deserves good software.*

A full-stack management system I'm building from scratch for our family bakeries. It handles inventory tracking, order management, sales reporting, and staff coordination — all through a unified dashboard. The crown jewel is the **joint cost allocation engine**: when one batch of dough gets split into Monay, Star Bread, Pandesal, and more — each with different sizes and prices — this system accurately breaks down cost-per-piece across shared ingredients so you can see exactly which bread is making you money.

**Stack:** React · Express.js · PostgreSQL · REST API

This isn't a tutorial clone. It replaces pen-and-paper tracking for a running business. 📋➡️💻

---

#### 🖥️ Home Server Lab
> *An HP laptop that thinks it's a data center.*

Self-hosted infrastructure running on a repurposed HP laptop with Ubuntu Server 24.04 LTS. Serves as the backbone for my projects and my Minecraft server.

**What's running:**
- 🐳 Docker + Portainer for container management
- 🔒 Nginx Proxy Manager with Let's Encrypt SSL
- ⛏️ Minecraft Fabric server (`mc.junparajes.com`)
- 🍞 Automate BMS (production deployment)
- 🔥 UFW firewall + fail2ban for security
- 🔑 SSH access on a custom port

Static public IP, no CGNAT. Built it from scratch in one sitting. It just works.

#### ⛏️ Minecraft Server
